# LEVENLOOS Discord Bot

Discord.py 2.7.1 bot voor de LEVENLOOS server.

De belangrijkste systemen zijn bereikbaar via duidelijke panelen:

- `/help` — permission-aware commandoverzicht
- `/adminpanel dashboard` — centraal beheer
- `/react manage` — React Roles / gradients
- `/voice config` — tijdelijke voice setup en defaults
- `/voice beheer` — beheer je eigen tijdelijke VC
- `/suggestie menu` — makkelijke suggestieflow
- `/suggestie beheer` — admin dropdown-beheer
- `/levels config` — levelsysteem
- `/health config` — Health Panel instellingen
- `/reminder maak` — persoonlijke reminder

Zie `DEPLOY_NOTES.md` voor deployment en `CODE_AUDIT.md` voor de revisiewijzigingen.
